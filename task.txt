1) What is a variable in JavaScript?
--A container used to store data values that can be accessed or manipulated in a program.

2) What are the three keywords used to create variables? 
--var, let, and const.

3) Syntax using var: 
--var variableName = value;

4) Syntax using let: 
--let variableName = value;

5) Syntax using const: 
--const variableName = value;

6) What is declaration? 
--Creating a variable by giving it a name without assigning a value.

7) What is initialization? 
--Assigning an initial value to a variable for the first time.

8) What is reassignment? 
--Changing the already initialized value of an existing variable to a new value.

9) What is redeclaration? 
--Declaring the exact same variable name again in the same scope using a declaration keyword.

45) what is the difference between let and const?
--let allows you to reassign a new value later, whereas const creates a constant variable whose value cannot be reassigned after declaration.

46) What is the difference between var and const?
--var allows both redeclaration and reassignment, while const forbids both redeclaration and reassignment

document.writeln()-- Writes raw HTML/text directly into the document stream, adding a newline character.
